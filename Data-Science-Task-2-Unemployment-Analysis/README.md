# Unemployment Analysis with Python

## Project Overview

This project analyzes unemployment trends in India using Python and the Unemployment in India dataset.

The analysis focuses on regional differences, monthly trends, employment indicators, and the impact of COVID-19 on unemployment.

## Objectives

- Analyze region-wise average unemployment rates.
- Study monthly unemployment trends.
- Compare unemployment trends across major regions.
- Identify the top 10 regions with the highest average unemployment.
- Analyze correlations between unemployment, employment, and labour participation.
- Compare unemployment rates before and after COVID-19.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset

The project uses the **Unemployment in India** dataset.

The dataset contains information about:
- Region
- Date
- Frequency
- Estimated Unemployment Rate
- Estimated Employed
- Estimated Labour Participation Rate

## Analysis Performed

1. Data loading and inspection
2. Data cleaning and type conversion
3. Descriptive statistics
4. Region-wise unemployment analysis
5. Monthly unemployment trend
6. Major region comparison
7. Top 10 regions by unemployment
8. Correlation heatmap

9. Pre-COVID vs Post-COVID comparison

## Conclusion

The analysis shows that unemployment rates varied across regions and over time. The COVID-19 period provides an important basis for comparing unemployment before and after the pandemic.

This project demonstrates the use of Python for exploratory data analysis and visualization of unemployment trends.
