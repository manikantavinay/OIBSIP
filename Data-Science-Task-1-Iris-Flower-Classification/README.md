# Iris Flower Classification

## Project Overview

This project classifies Iris flowers into three species using machine learning.

The three species are:
- Setosa
- Versicolor
- Virginica

## Dataset

The Iris dataset from Scikit-learn was used for this project.

It contains four features:
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

## Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Analysis Performed

- Exploratory Data Analysis
- Dataset shape and data type inspection
- Missing-value check
- Descriptive statistics
- Pairplot analysis
- Box plot analysis
- Feature selection discussion

## Machine Learning Models

Two classification models were trained:

1. Logistic Regression
2. Decision Tree Classifier

## Model Performance

| Model | Accuracy |
|---|---:|
| Logistic Regression | 96.67% |
| Decision Tree | 93.33% |

Logistic Regression achieved the highest accuracy and was selected as the best-performing model.

## Conclusion

Petal length and petal width were found to be important features for distinguishing the Iris species.

Logistic Regression performed better than the Decision Tree on the test dataset with an accuracy of 96.67%.
